Делаю чат Kroshka для семьи, друзей и тд и тп на C# .NET 10 (Self Contained сборки тоже надо)
Это будет как мессенджер полноценный (посмотри как в DPT Social сделано)
Только для локальной сети + настраиваемые конфиги например включать регистрацию и авторизацию чтобы можно было использовать не только в локалке
WebView2 окно - это его GUI (HTML CSS JS (fas fa - оффлайн, в vendor скопируй фулл) ease math sound) и полноценный трей
Неймспейсы будут DPT.*
гит гитигнор красивый ридми иконку лого документацию и тд и тп
Репо будет тут https://github.com/dpteam/Kroshka
и будет Github CI с артефактами (билдами)
Динамическая отказоустойчивость (типа тру катчи всякие и тд и тп)
Логирование через Trace (и в лог и в файл) без App.config и без бага задвоения листенера
Цвета бренда: светлое #0088FF (осн), #0080FF (осн2), #FFFFFF (фон), тут точно, а вот темная: #000088, #000000 (не точно) и OLED там тем более хз) - тут подбери лучше для темных тем цвета сам, для светлой я уже обозначил
НО все дебрендировано (настраиваемый бренд)
Базу данных сделай по-простому без SQL и тд и тп, например файлами и папками (как в DPT Social), даже контент
Для LAN будет мастер сервер (например на сервере) и клиенты подключатся к нему. Можно будет сделать выбор сервера в настройках.
И важно - для каждой функции есть конфиг и настройки, чтобы каждый мог себе построить чат для себя.
Будет сервер и клиент. Для LAN по-умолчанию без регистрации и авторизации, просто войти под ником и запомнить вход. (В моем случае надо как-то по умному сделать запоминание, т.к. хочу использовать чат для семьи, как альтернатива для Telegram только в пределах локалки, там будут ещё "комнаты" и лички, т.к. через ZeroTier друзей буду подключать. )
Будет и Андроид клиент в ближайшем будущем, пока только план (посмотри как в AutoZapret сделан апп для андроида) ну и для Линукса тоже будет клиент.
Хостится должно на 0.0.0.0 (хоть и LAN но там NAT так что ок) и скрипты напиши для разрешения брандмауера
Порт например 6767 будет (если свободен, проверь) для сервера.
